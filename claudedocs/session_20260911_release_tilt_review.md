이번 case의 신규 변수: [배출 회전축/각도 (오프라인 기구학 섭동만)]. 사용자가 사진의 잔류 알을 보고 흔들기 없이 작은 회전으로 배출 가능한지 확인 요청. 기존 실물 토크/PID case에 새 배출 동작을 몰래 합치지 않는다.

출력: `claudedocs/runtime_logs/grab_track/g19_servo_direct/s1_v1_real/boot_check_20260911/release_tilt_review_01/`.

검토 순서: 사진 원본 재검수 → 실제 torque900_03 배출 마지막1초 원시 관절각 확인 → S1 고정 보울/출구 형상 대조 → 손목 피치/롤 및 이상적인 출구방향 기울임의 중력 투영 비교 → 실제 측정과 가상 후보를 구분한 RRD/PNG 검증·육안 검수.

완료 조건: 원시 배출 구간·각도 및 형상 SHA 보존, 후보별 출구방향 경사·옆벽방향 중력·립 변위 정량화, 정확한 엔티티/타임라인/컴포넌트 RRD 검증·스크린샷 실제 검수, 실물 배출 성공 여부와 기구학 결과 분리. 실제 로봇 구동0, 접촉/마찰 시뮬레이션0.

실패 가능한 비교: 작은 손목 회전이 출구방향 경사를 실질적으로 높인다는 가설을 좌표 변환/형상으로 확인한다. 이는 기구학 섭동 평가이며 입자 이동/배출을 시험한 실기나 DEME 실험이 아니다. 새 실기 미실행 사유는 사용자의 확인 요청 범위가 사진/방향 검토이고, 사진 촬영 후 로봇/컵 현재 배치가 확인되지 않았기 때문이다.
