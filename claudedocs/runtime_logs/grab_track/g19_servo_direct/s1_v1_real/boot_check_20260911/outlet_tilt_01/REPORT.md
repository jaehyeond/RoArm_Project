# 현재 열린 자세에서 출구 기울임 실제 시험

목적: 사진 속 고정 jaw 잔류에 대해 출구 쪽 경사를 실제로 늘린다. 새로 퍼내지 않고 현재 잔류로 시험한다.

1. T105만 조회하여 직전 열린 배출 자세가 그대로임을 확인.
2. 직전 발행 목표 기준 립5cm 상승, 수직 공구의 롤−5→90도 정렬, 출구 쪽20도 기울임 경로 계산.704개 보간 자세의 S1/팔 분리평면·관절 범위 검사 및 Rerun 사전 검수.
3. 문30·토크200으로64개 계획 T122를 순서대로 전송. 마지막40번째 기울임 단계에서 어깨 편차5.014578도가 기존5도 기준을 넘어 추가 움직임 없이 정지.
4. 원시2935행·58.143003초 저장. 출구 경사7.762060→22.001692도(관절값 기반), 공구 자체 최종 기울기14.501953도. 문29.267578도 유지. 후 계량/잔류 입력은 아직 null.

**판정: 올바른 출구 방향 기울임은 관측했으나, 제어 완료는 FAIL. 전량 배출/배출량 개선은 아직 판정할 수 없다.** 목표20도는 전송했지만 실제로20도 기울었다고 보고하지 않는다.5도 보호 기준/PID/토크는 변경하지 않는다. 현재는 열린 기울임 자세이며 HOME/P1이 아니다.

- 계획: `plan_01/plan.json`, `interpolation.json`, `arm_clearance.json`, `visual_01/`.
- 실기: `execution_01/{raw.jsonl,result.json,analysis.json,command_audit.json,feedback.csv}`.
- 실제 전체 재생: `execution_01/visual_01/{release.rrd,release.rbl,rerun_validation.json,release_rerun.png,inspection.json}`. Rerun0.34.1·전체2935행 읽기 대조PASS, PNG3실제검수.
- 모델 검증 한계: 외부 위치/접촉/컵 위치/입자 수는 계측하지 않았다. nominal 보간 검사는 임의 서보 오차를 포함하는 연속 충돌 보증이 아니다.
- 코드 보정: 실기 동결 드라이버는 result.completed=false인데도 shell0을 반환했다. 정본 드라이버의 종료코드를 실패2로 고쳤고, 가짜 시리얼의 마지막5.01도 편차 회귀와 기존 문 목표 유지 회귀를 통과했다. 실물 재실행은 하지 않았다.
