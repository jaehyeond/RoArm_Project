# 작은 배출 회전 검토 — 방향을 맞춘 기울임은 타당한 후보

**출구가 낮아지는 방향으로 고정 jaw를 기울이면 잔류 배출을 도울 가능성이 있다. 실제로 몇 도에서 몇 알이 떨어지는지는 아직 시험하지 않았다.**

1. 사용자 사진에서 고정 jaw 안쪽 모서리/턱에 알이 모여 있음을 재확인했다. 약10~15알은 사용자 추정이다. 각 알의 위치를 CAD 좌표로 보정하거나 끼임 원인을 확정하지 않았다.
2. 현재 `hw_s1_manual.py:196` 배출은 문30° → 정착 확인 →1.5초 대기 → 닫기다. 고정 jaw를 기울이는 단계가 없다. 실제 마지막 열기 명령~닫기 명령은4.110019초로, 이 전체를1.5초라고 오기하면 안 된다.
3. `torque900_03/raw.jsonl:3035`부터 닫힘 직전3090까지 마지막1초의 수신51행 관절각은 동일했다. 이 각도와 S1 모델로 계산한 공구의 옆기울기는3.251953°. 사진에서 각도를 재어 얻은 값이 아니다.
4. 고정 보울 출구 직전 내측면 `s1_v1/fixed_wall_11.stl`의 설계 경사는7.499999°. 사진에서 알이 놓인 면과 정확히 같은 면이라고 확정하지는 않았다. 작은 회전의 효과를 비교하는 후보 표면으로 사용했다.

손목 피치는 현재 장착 방향에서 주로 보울의 폭 방향으로 기울인다. 손목 롤은 거의 수직인 공구축 주위를 돌려 출구 경사가 조금만 변한다. 따라서 손목 각도5°라는 숫자만으로 출구가5° 기울었다고 보면 안 된다. 고정 jaw를 실제 출구 방향으로 기울이는 동작의 관절 조합과 컵 위 위치 유지가 필요하다.

표면에서 미끄러지기 시작하려면 기울기에 따른 중력이 정지 마찰을 이겨야 한다. [OpenStax, University Physics Volume 1 §6.2 Friction](https://openstax.org/books/university-physics-volume-1/pages/6-2-friction). 이번 PP 펠릿과 출력 표면의 마찰·모서리 접촉은 측정하지 않았으므로5°면 전부 떨어진다고 단정할 수 없다.

**다음 확인 방법:** 같은 컵 위에서 문30°를 유지한 채 한 방향으로 작게 기울여 잠시 유지하고, 추가 배출 질량과 남은 알 수를 기록한다. 흔들기 반복 없이 작은 단일 기울임부터 비교할 가치가 있다. 이 문서는 방향 검토이며 실제 구동 계획 승인이 아니다. 현재 실물 배치·컵 여유를 확인하고 관절 경로를 정한 후 실행해야 한다. 기존900↔790의 리프트 각도 비교와 새 배출 동작의 질량 비교는 조건을 명시하여 구분한다.
