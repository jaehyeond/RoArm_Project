### 원인 기작 (DEME 2.4.0 커널 원문으로 확인)

`share/DEME/kernel/DEMCollisionKernels.cu` `triangle_sphere_CD`(힘 계산용, `DEMCalcForceKernels.cu:179` 에서 호출):

```
h = dot(sphere_pos - A, face_n)          // 면 법선 방향 부호 높이
if (투영이 삼각형 안) { depth = h - radius; normal = face_n; in_contact = (-radius < h < radius); }
else                  { depth = |P - 최근접점| - radius; ... }
```

즉 **양면 접촉**이며, 구 중심이 면 뒤쪽(h<0)이라도 투영이 삼각형 안이면 관입 = radius − h = **r + |h|** 로 잡는다
(닫힌 볼록체 안에 잠긴 구를 밀어내기 위한 설계 — CD 단계의 `triangle_sphere_CD_directional` 주석 참고).
따라서 **면 법선이 실제 바깥과 반대로 향하면**, 그 면의 발자국 안·뒤쪽(= 실제로는 바깥, 정상 위치)에 있는 구가
h = −(면까지 거리) 로 읽혀 관입 r+|h| ≈ 2~4 mm, Hertz 힘 ≈ 30~70 N 을 받는다. 구 하나(36 mg)에 60 N 이면
가속도 1.7×10⁶ m/s² → 1 ms 안에 수십 m/s = W3 타임라인의 "0.5 ms 안에 0.05 → 68 N, 입자 41 m/s".

내 셸 생성기(`half_bowl`)의 파팅면(x = 8.1 평면의 립·윗단·캡 단면 12면)은 outward 를 `(0, 0, cos t)` 로 줬는데
이 벡터는 실제 면 법선(±X)과 직교(내적 0)라 `>= 0` 판정이 winding 그대로 통과 → 방향이 임의. 실측: W3 셸 고정부
20면 중 8면, 진단 셸 12면 중 4면이 −X(고정 반쪽 안쪽 방향). 뒤집힌 파팅면의 뒤쪽 = **문 쪽 반공간 전체**이고
발자국(립 띠 z 165~169.6·|y|≤18.2, 캡 단면 z 120~170·18.2<|y|<23.2)은 잠김 중 펠릿이 정상적으로 지나는
입(mouth)·립 옆 영역이다. → 잠김이 깊어져 펠릿이 그 발자국에 들어오는 순간(W3: 7~20 mm) 터졌다.

같은 이유로 W3 진단 표의 "강성 올리자 더 빨리 터짐(E 1e8, 잠김 2 mm)" 도 설명된다: 유령 관입 r+|h| 은
강성과 무관한 기하량이라 힘 ∝ E 로 커진다. 옛 2매 셸(잠김 8 OK / 18 발산, HANDOFF §D-f)도 STL 조각 합집합의
내부 중복면(법선 반대 쌍)이 같은 기작으로 작동했을 가능성이 크다(미검증).

DEME 가 터지던 이유는 물리가 아니라 내 셸 메시의 면 방향 실수였고, 고치니 실물 절차가 그대로 돌아간다. 회당 포획 질량은 **평균 11.8 g**(설계 가정 17.6 g 의 67 %, seed 3회 COV 3.7 %)이며, 문은 펠릿 1.5 알 두께의 틈을 남기고 멈춘다. 이 수치는 **임시 물성(실측 전)·구형 입자** 로 나온 값이라 오늘 실물 계량(n≥5)과 "같다/다르다" 를 판정하는 데는 쓰지 말고, 실측 물성(밀도·마찰·안식각)과 쌀알형 클럼프(`particle_shape: clump2`, 클럼프로 재정착한 더미 필요)를 넣은 뒤 다시 돌려 비교할 것. 다음 후보(승인 사항): ① 실측 물성 JSON 교체 + 클럼프 더미 재정착 ② 서보 토크 환산(0.9×1.96) 실측(실물 정지각 2.8~3.5° 를 맞추는 토크 역산) ③ ③번 더 깊은 더미는 **불필요**(원인이 더미 깊이가 아니었음 — 실행 안 함) ④ 옛 2매 셸 STL(조각 합집합 내부 중복면)도 같은 기작인지 확인하면 HANDOFF §D-f 의 "insert 18 발산" 이 설명된다.
