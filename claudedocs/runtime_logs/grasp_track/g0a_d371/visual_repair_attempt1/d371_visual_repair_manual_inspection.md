# D371 시각자료 원본 해상도 수동 검사

검사 일자: 2026-07-21 KST

## 결론

- 교수님용 직접 비교판 3장은 모두 1920×1080이며 한글, 후보명, 실제 충돌체 수,
  물리 미실행 경계가 겹침이나 잘림 없이 읽힌다.
- RRD는 절대경로 Rerun CLI로 footer, 787개 비시스템 entity, component,
  `blueprint`/`log_time` timeline 계약이 모두 PASS했다.
- Rerun 캡처는 Viewer의 HiDPI 2배 배율 때문에 요청 3840×2160이 아니라
  7680×4320으로 저장되었다. 또한 Rerun 패널의 한글 일부가 네모 문자로 표시된다.
  따라서 이 캡처는 재생 구조 검사에는 유효하지만 교수님용 최종 판으로는 사용하지 않는다.
- 원통 물리 스텝, q5, 실제 접촉, 파지 시험은 수행하지 않았다.

## 파일별 관찰

### 상한 비교판

- 원본/A/R64/R32 네 열과 link5/움직이는 턱 두 행이 정확하다.
- A와 R64는 육안상 거의 같고, R32는 실제 32개라는 표기가 명확하다.
- 하단에 물리·접촉·q5·파지 미판정 경계가 보인다.

### 의미 보존 비교판

- C1은 link5 5개·움직이는 턱 18개, C2는 11개·24개로 표시된다.
- C1/C2의 초록색 단일 remainder가 넓은 빈 공간을 메우는 형상이 뚜렷하다.
  이는 frozen-OPEN에서 link5가 원통과 겹친 수치 결과와 시각적으로 일관된다.
- 보존 조각은 노란색으로 구분된다.

### 접촉면 확대판

- 청록색 원본 접촉면과 노란색 보존 후보 조각을 구별할 수 있다.
- C1/C2에서는 초록색 remainder가 접촉부 주변을 크게 덮는 문제가 보인다.
- 제목, 각 후보의 실제 개수, 행 이름은 겹치거나 잘리지 않는다.

### Rerun 캡처

- 두 행 × 다섯 후보 뷰와 오른쪽 알림 여백이 존재한다.
- 알림 3개는 오른쪽 여백에만 있어 후보 형상을 가리지 않는다.
- `Unknown timeline`이나 빈 metric panel은 없다.
- 패널 한글 일부가 네모 문자이며, 실제 PNG는 7680×4320이다. 이 두 이유로
  사전등록된 Rerun presentation completion은 FAIL로 보존한다.

## 사용 권고

교수님께는 3개의 1920×1080 직접 비교판과 수치표를 보여준다. Rerun 캡처는
재생 가능성과 후보 배치 확인용 보조 증거로만 사용한다.
