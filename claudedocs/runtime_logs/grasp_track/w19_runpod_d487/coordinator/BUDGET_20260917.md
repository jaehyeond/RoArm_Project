## 5. 실행 순서 (각 단계 영수증)
1. 키 교체 → `list-pods` 로 랩 계정 확인(지훈·지나 pod id 를 **금지 목록**으로 기록).
2. pod A 생성 → SSH → `bootstrap_pod.sh`(miniconda 3.11 @ 같은 절대경로, deme 휠 sha 대조, 꾸러미 해시 대조, 환경 영수증).
3. smoke 3종: `smoke_import_300`(≈1~2 min) → `smoke_sphere_regression`(로컬 105 s, 판정 268~362알·servo_stall) → `smoke_settle_full`(로컬 127 s → **속도비**).
4. 속도비·예상 종료 시각 보고 → **사용자 GO** → `runA_full_cycle` 을 `setsid nohup` 로 기동(러너 상한 43,200 s).
5. pod B 동일 부트스트랩 → GO → `runB_seed461` → `runB_seed462`(순차, pod 당 DEME 1개).
6. rsync 회수 → 로컬 해시 대조 → Terminate → 로컬 회계(rev31/rev32)·Rerun·Isaac·독립 감사는 다음 세션.
