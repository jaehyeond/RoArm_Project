# D348 attempt4 Rerun 수동 화면 판독 — 글꼴 실패 보존

- 원본 해상도 `4800×2800` PNG를 직접 확인했다.
- 여덟 형상, `5%`, `256/256`, `128/128`, `D347 HOME-near`, `q5=0 CLOSED`,
  `0 steps`, `D348 offline`, `G0a=false`는 모두 읽혔다.
- 오른쪽 48자 완료 이벤트도 `G0a=false`까지 잘리지 않았다.
- UTF-8 저장으로 `\\u...` 표시는 사라졌지만, Rerun 0.34.1 내장 글꼴에서 한글은
  누락 글리프 네모로 표시됐다.
- 사전 등록한 “한글 실제 글자 판독” 조건을 충족하지 못했으므로 attempt4 수동 판정은
  실패다. 수치·과학 판정은 유지한다.
- 다음 시도는 Rerun 화면의 검증 문구를 짧은 ASCII로만 고정하고, 동일 의미의 한국어
  설명은 상태 문서와 사용자 브리핑에서 제공한다. 물리·과학 설정은 바꾸지 않는다.
