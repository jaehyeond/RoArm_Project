# D348 attempt3 Rerun 수동 화면 판독 — 실패 보존

- 원본 해상도 `4800×2800` PNG와 attempt2 결정 그림을 직접 확인했다.
- 조각 45의 네 형상, 전체 그리퍼의 네 형상, `5%`, `256/256`, `128/128`,
  `g0a_pass=false`는 화면에서 확인됐다.
- 그러나 HOME 설명의 한글이 `\\u...` 문자열로 표시됐고, 오른쪽 완료 이벤트는 긴
  한 줄이 잘려서 `D347=HOME 근방`, `D348=오프라인 재판독`의 구분을 화면만으로 끝까지
  읽을 수 없었다.
- 따라서 수치·과학 판정은 유지하되 attempt3의 수동 화면 완료 조건은 실패다.
- 다음 시도는 저장된 동일 증거를 짧은 줄바꿈 요약으로 다시 표시하는 데만 한정한다.
  PhysX 실행, 물리 step, 자산 변경, cook 요청, 목표 질의, 허용값 변경은 하지 않는다.
