# D347 Rerun 실제 화면 확인 — 관찰성 PASS

- 확인 방식: Rerun 화면과 별도 판정 PNG를 모두 `view_image`, `detail=original`로
  직접 열었다.
- Rerun 화면: `4800x2800`. link5와 gripper_link 각각에 대해 원본,
  실제 인스턴스, prototype, 후보의 네 패널, 총 여덟 패널이 모두 보였고 형상도
  비어 있지 않았다.
- 진단 내용: 주황색 목표 원통, 등록 좌표 표시, Float64 수치 표, cook/gate 사건
  표가 보였다. viewer 알림은 우측 상단 가장자리에 겹치지만 패널 제목이나 판단에
  필요한 후보 형상을 가리지는 않았다.
- 별도 판정 그림: `1076x665`. `witness_manifest_256=True`,
  `fresh_live_audit_128=False`, 그리고 불완전한 형상 합집합으로 목표 거리를
  계산하지 않았다는 정지 문구를 읽을 수 있었다.

따라서 **Rerun 관찰성 완료 조건은 PASS**다. 이는 “화면과 기록 장치가 제대로
작동했다”는 뜻이다. 픽셀은 형상·부피의 수치 증명이 아니며, link5 `part_045`의
부피 교차검사 실패를 뒤집지 않는다. D347의 과학 판정은 계속 FAIL이고,
목표 거리·settle·G0a는 허가되지 않는다.

비차단 주의: Rerun CLI는 사건 로그의 `part_idx` 시간축을 비정렬로 표시했다.
다만 `event_idx`와 `log_time`은 정렬되어 있고, 등록된 시간축 이름·footer·엔티티·
컴포넌트 계약은 통과했다. 이 주의사항은 후속 관찰성 개선 대상으로만 보존한다.
