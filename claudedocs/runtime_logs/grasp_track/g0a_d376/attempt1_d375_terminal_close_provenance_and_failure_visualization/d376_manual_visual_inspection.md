## 관찰

두 1920×1080 설명판은 제목·본문·화살표·하단 판정이 잘리거나 겹치지 않았다. 첫 판은 D375의 측정 완료와 종료 미완료를 분리하고, 증명된 사실과 두 원인 후보를 다른 상자에 둔다. 둘째 판은 D351/D367/D373/D375가 같은 실패가 아님을 네 행으로 구분한다.

Rerun 캡처는 HiDPI 때문에 실제 3840×2160으로 저장됐다. 여섯 시간 사건과 세 정적 판정 문장은 모두 보이며 ASCII 글리프도 정상이다. 다만 timestamp 축은 1970년 날짜 형식으로 보여 초보자가 초 단위 지속시간을 바로 읽기에는 덜 직관적이다. 따라서 정확한 시간 수치 권위는 원 JSON이고, 쉬운 설명 권위는 두 1920×1080 판이다.

우측 상단의 `message proxy server crashed: Operation not permitted` 토스트는 샌드박스가 로컬 메시지 서버를 막은 진단 경고다. 저장된 RRD 로딩·표시·스크린샷은 return 0이고 엄격한 파일 계약도 PASS했으므로, 이 경고를 D375 수명주기나 과학 판정으로 해석하지 않는다.

## 판정

원본 해상도 육안검사 PASS. 이 판정은 D376 관찰 가능성 계약만 닫으며, D375 full identity, P34 물리 동등성, 원통 전도, 파지 가능성은 승격하지 않는다.
