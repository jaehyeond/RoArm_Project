## 2. D458 — jaw stroke 실물 재실측: 80 mm (실물 전용)

63rd `:131`이 요구한 캘리퍼 재실측을 **드디어 실행**. RoArm-M3-Pro 1대(`/dev/ttyUSB0`),
계측 = 사용자 육안 + 강철자, 교차검증 = Kinect DK 컬러 프레임 눈금 픽셀 판독(약 11 px/mm → 80~86 mm).

- `cmd 89°` → `state 88.77°`, 1.35 s / 폴링 18회 안정, **스톨 없음**
- 계측 정의 = **고정 조 면 → 완전개방 가동 조 팁**. 팁 기준인 이유 = 넓은 패드가 없는 **얇은 블레이드 2매** 구조
- 결과 **약 80 mm**
- 🔴 기존 피팅 `jaw_mm ≈ 0.75 × state°`는 **0~38°에서만 실증**된 것이고, 89° 외삽값 66.6 mm는
  **약 17 % 과소**였다. **단일 회전 조의 개구는 각도에 선형이 아니다 — 외삽 금지.**

**부수 확정 3건**

1. **`cmd° ↔ state°`는 거의 1:1** (편차 −0.3° 이내 일정, 30°는 3회 재현). 서보 위치 제어는 신뢰 가능.
   ⚠️ 단 **`state° ↔ URDF θ` 불일치는 미해소**(30 mm 물체가 물리 37.9° / sim 22.8°에서 정지). 별건.
2. 🔴 **관측자 효과 실측 재현** — `tech_servo_observer_effect.md` 그대로.
   `cmd=60` + blind `time.sleep(3.0)` → **5.63°에서 멈춤**(약 2 deg/s). `joints_angle_get()` 연속 호출로
   바꾸면 0.4~4 s 내 정상 도달. ⚠️ `gripper_stroke_probe.py`의 `SETTLE_S = 3.0` 주석("3s = full arrival")은
   **읽기가 잦은 맥락에서만 참** — 복사하면 조용히 틀린 각도를 기록한다.
3. **어깨 중력 처짐** — 읽어서 되먹여 명령하면 호출당 **+0.7° 누적**(2.81→3.52→4.13). 자세를 인자로
   고정하면 누적은 멈추나 **목표로 되돌아가지는 못한다**(err +1.32). 서보는 위치를 유지할 뿐
   중력으로 처진 만큼을 다시 들어올리지 않는다. → 63rd `:136` 페이로드 우려의 **첫 증거**.

## 5. D461 — 셸 v1→v2 3연속 정정 (설계 전용)

**계기 = 사용자의 "이거 3D로 좀 돌려볼 수 없음?"**

**정정 ① 볼트 구멍 2.8 → 3.4 mm.** 사용자: **"지금 구멍이 너무 타이트해. 안 들어가져."**
FDM은 구멍이 0.1~0.3 mm 작게 출력 → 2.8 설계가 실효 2.5~2.6이 되어 M2.5(외경 2.5)와 간섭.
ISO 273 M2.5 관통 = close 2.9 / **normal 3.4**. 3.4는 FDM 수축 + **스팬 오차(25.0 vs 25.2 + 래스터 오차)**
까지 함께 흡수한다. → **FDM 설계에서 끼워맞춤 구멍은 공칭치로 잡으면 안 된다.**

**정정 ② 🔴 셸이 조인트 축과 무관한 자리에 있어 두 개가 완전히 겹쳤다.**
`build_shell()`이 `moving` 플래그로 **측판 인터리브 1.2 mm만** 다르게 주고 나머지를 **동일한 로컬 원점**에서
생성. 즉 **각 셸이 자기 조에 붙었을 때 어디에 놓이는지가 설계에 전혀 없었다.**
→ 운동학 유도(한쪽 조만 회전하므로 립-투-립 = `2·R·sin(θ/2)`):
```
58 mm = 2·R·sin(89°/2) = 1.4018·R   →   R_lip = 41.37 mm
θ=0° 0.00 / 15° 10.80 / 30° 21.42 / 45° 31.67 / 60° 41.37 / 75° 50.37 / 89° 58.00 mm
```
R=41.37은 가동 조 칼라 구간 X 38~52.5 안에 들어간다 — 마운트와 립이 같은 영역이라 구조적으로도 자연스럽다.

**정정 ③ 🔴 축 규약이 URDF와 반대였다.** 정정 ② 이후에도 Y 중첩 40 mm 잔존. URDF 재확인:
```
조인트 축      Z   (link5_to_gripper_link, axis xyz="0 0 1")
블레이드 뻗음  X
블레이드 폭    Z   ← 회전축과 나란함
판재 두께/간격 Y   ← 두 조가 갈라지는 방향
```
그런데 `arc_segment()`는 **X-Z 평면에 호를 그리고 Y로 밀어내고** 있었다.
즉 **4.05 mm만 갈라져야 할 Y에 셸 폭 40 mm를 넣은 것.**
→ **보울 반원은 회전 평면 X-Y에, 셸 폭은 힌지축 Z를 따라**로 정정.
→ 추가로 보울이 항상 +Y로만 자라 고정 셸이 반대편으로 안 갔다 → 고정 셸만 반원 각도 π~2π로 회전.
**결과 Y 중첩 −0.05 mm** (닫힘 시 두 립이 정확히 맞닿음).

**조 기하 실측 (link5 좌표계, cmd=0 닫힘)** — `origin xyz="0 0.018821 0.052035" rpy="-1.5708 -1.5708 0"`,
회전은 **고정축 `Rz@Ry@Rx`**(session_20260424 FK 버그 수정 규약):
```
고정 조 판재  X −11.54 ~ −10.03   (안쪽 면 −10.03)
가동 조 판재  X  −5.98 ~  −4.47   (안쪽 면  −5.98)
        → 닫힘 시 두 판 사이 빈 간격 4.05 mm
```
⚠️ 초기 "6.54 mm"는 **정점 평균 거리**(분포 편향 포함)였다. **판재 면 기준 4.05 mm가 맞다.**
🟢 **안쪽 = X가 큰 쪽**(가동 조 방향). 두 판 사이가 펠릿이 들어가는 공간.
🟢 **마운트 플레이트는 조 판재 바깥면에 붙인다** — 안쪽은 보울 공간이라 점유하면 닫힐 때 충돌.
구조 = `[플레이트] [조 판재 1.5] [셸]` 샌드위치를 M2.5가 관통. **1.5 mm 판재가 양쪽에서 지지되어
과조임 변형도 완화된다.**

**보울 해상도 `seg_n` 10 → 20.** 18°/조각은 반원이 각져 **펠릿이 모서리에 끼거나 유동이 실물과 달라질**
수 있다. 대가 = 조각 21→31, 자중 25.76→25.93 g(상한 50 이내).

### 🔴 §6 메타 교훈 — 수치 게이트는 공간 배치 오류를 못 잡는다

정정 ②·③이 있는 동안 **설계 게이트 5종이 전부 PASS**였다:
`all_pieces_convex` · `tool_mass_under_max` · `open_close_ratio_in_real_band` ·
`particle_ratio_min10` · `fits_in_measured_jaw_stroke`.
**자중·개구비·입자비는 셸이 어디에 놓이든 계산이 성립하기 때문이다.**
두 셸이 완전히 겹쳐 있어도, 축이 90° 뒤집혀 있어도 통과했다.

→ **파라메트릭 생성기에는 스칼라 게이트만으로 부족하다. 형상 검증이 필요하다.**
→ 최소 조치 = **두 셸의 Y 중첩 검사**(닫힘 시 0 근처. 40 mm였다면 즉시 FAIL).
**⚠️ 본 세션은 렌더로만 확인했고 게이트화는 미실행 — 이월된 유일한 조치.**
