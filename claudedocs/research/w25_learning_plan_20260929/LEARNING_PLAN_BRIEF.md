# 퍼내기 위치 학습 — 방향 정리 (2026-09-29)

> 대상: 교수님 질문 "로봇이 다음 위치를 어떻게 효율적으로 찾아 퍼낼지, 그걸 어떻게 학습하고 데이터를 어떻게 모을 거냐"에 대한 정리. 선행 논문 요약은 `~/Downloads/proposal_priors_package_20260929/` 참고.

## 0. 한 줄 요약

딥러닝 모델로 "퍼내면 얼마나 잡히고(질량) 더미가 어떻게 남는가(높이지도)"를 **지도학습**하고, 실물 차이는 가우시안 과정(GP)으로 보정하며, 다음 위치는 그 예측기로 후보를 **탐색해** 고른다. 강화학습은 1단계에서 쓰지 않는다.

## 1. 용어 정의 — 딥러닝과 지도학습은 다른 층위다

### 1-1. 지도학습 (supervised learning) = "학습 방식"
- **학습 데이터가 (입력 x, 정답 y) 쌍으로 주어지는 학습 방식**이다.
- 모델은 **x 만 입력으로 받는다.** 정답 y 는 입력에 넣지 않는다.
- y 는 학습할 때 **채점에만** 쓴다: 모델이 낸 예측 ŷ 와 정답 y 의 차이(오차, loss)를 계산하고, 그 오차가 줄도록 모델을 고친다.
- 다 배운 뒤 실제로 쓸 때는 **x 만 있고 y 는 모른다** — 모델이 y 를 예측한다.
- 비유: 문제집(문제 + 정답지)으로 공부하는 방식. 문제를 풀 때 정답지를 보지 않고, 푼 뒤 정답지로 채점하고 틀린 부분을 고친다.

### 1-2. 딥러닝 (deep learning) = "모델 종류"
- **여러 층으로 쌓은 인공신경망**을 쓰는 방법이다. 층마다 수많은 가중치가 있고, 오차가 줄어드는 방향으로 가중치를 조금씩 고치는 방식(경사하강)으로 학습한다.
- 높이지도 같은 **격자·이미지형 입력**에서 모양을 스스로 뽑아내는 데 강하다(CNN, U-Net 등).
- 비유: 공부하는 학생의 두뇌 구조.

### 1-3. 둘의 관계
| 조합 | 뜻 | 예 |
|---|---|---|
| 딥러닝 + 지도학습 | 신경망을 (x, y) 쌍으로 학습 | **우리 예측기** |
| 딥러닝 + 강화학습 | 신경망 정책을 보상으로 학습 | 알파고 류 |
| 딥러닝 아님 + 지도학습 | GP·선형회귀 등을 (x, y) 쌍으로 학습 | **우리 실물 보정(GP)** |

"딥러닝으로 지도학습한다" = **학습 방식은 지도학습, 그 안에 쓰는 모델이 신경망**이라는 뜻이다. 정답을 입력에 넣는다는 뜻이 아니다.

### 1-4. 우리 문제에 대입
| 구분 | 내용 |
|---|---|
| 입력 x | 퍼내기 **전** 높이지도(퍼낼 위치 주변 패치) + 퍼낼 위치 (x, y) |
| 정답 y | ① 잡힌 질량 m ② 퍼낸 **뒤** 높이지도 |
| 학습 | 신경망이 x 로 ŷ 를 내고, (ŷ − y) 오차를 줄이도록 가중치 수정 |
| 사용 | 새 더미에서 후보 위치마다 x 를 넣어 ŷ(질량·남는 형상)를 **퍼내지 않고** 예측 → 가장 좋은 위치 선택 |

## 2. 목표·상태·지표를 분리한다 (질량이냐 높이지도냐)

세 가지는 역할이 다르다. 같은 말이 아니다.

| 역할 | 무엇인가 | 우리 정의 |
|---|---|---|
| **목표 (task goal)** | 로봇이 끝내야 할 일, 에피소드 종료 조건 | **정해진 질량 M\* 를 용기에 옮기기**(프로포절: "정해진 양 완료까지 반복") |
| **상태 (observation)** | 결정할 때 보는 것 | **높이지도**(상자 좌표 5 mm, 62×44) |
| **예측 대상 (model output)** | 예측기가 맞히는 것 | 질량 m(방법①·②) + 퍼낸 뒤 높이지도(방법② 전용) |
| **지표 (metrics)** | 목표를 얼마나 잘 달성했나 | M\* 까지 **퍼내기 횟수·총 시간·실패율** |
| **기준선 (baseline)** | 넘어야 할 단순 규칙 | 무작위 · 최고점 · 발자국 안 부피 최대 — **같은 목표·같은 지표**로 평가 |

- **질량 = 목표를 재는 단위**, **높이지도 = 판단 근거이자 형상 예측의 출력**이다.
- 횟수·시간·실패율은 목표가 무엇이든 "그 목표를 얼마나 빨리·안정적으로 이뤘나"를 재는 지표라 그대로 유지된다.
- 방법①(질량만 예측) vs 방법②(질량 + 남는 형상 예측)의 비교가 기여 2 이며, 둘 다 같은 목표(M\*)·같은 지표로 잰다.

### 2-1. 교수님 제안대로 "높이지도 먼저" 할 때
- 1단계 산출물 = **형상 예측기**(퍼낸 뒤 높이지도 예측). 평가 = 예측 오차(mm)이며, 목표 M\* 는 아직 쓰지 않는다.
- 단, **질량은 기록은 계속한다**(시뮬은 입자 수로 공짜, 실물은 저울로 십수 초). 나중에 목표 M\* 평가에 바로 쓰기 위해서다.
- 질량 없이 과업 목표가 꼭 필요하면 대안 = **"지정 구역의 모든 칸을 문턱 높이 아래로 비우기"**. 옆으로 밀기만 해서는 달성할 수 없으므로 높이지도만으로도 공정하다. 반대로 "상자 전체 부피 감소"는 목표로 쓰면 안 된다: 한 번 퍼낸 12 g 는 상자 전체 높이로 0.35 mm 인데, 체계 오차 1 mm 가 34 g 에 해당한다.

## 3. 방식 분류 — 머신러닝·딥러닝·강화학습 중 무엇인가

| 부분 | 하는 일 | 방식 | 모델 |
|---|---|---|---|
| ① 결과 예측기 | (높이지도, 위치) → 잡힐 질량 | 지도학습(회귀) | 작은 CNN 또는 "딥 평균 모델 + GP"(CoDeGa) |
| ② 형상 예측기 | (높이지도, 위치) → 퍼낸 뒤 높이지도 | 지도학습(영상→영상) | U-Net 류 CNN (Aoshima 의 세계모델 Φ 역할) |
| ③ 위치 선택 | 후보를 예측기로 채점해 선택 | **학습 아님 — 계획/탐색** | 방법① 탐욕(질량 최대) / 방법② 앞보기 트리 탐색 |
| ④ 시뮬→실물 보정 | 실물에서 틀리는 만큼 보정 | 지도학습(잔차 회귀) | GP |
| ⑤ (선택) 강화학습 | 위치 선택 정책 자체를 학습 | RL | 나중에, 학습된 예측기 안에서만 |

강화학습을 1단계에서 쓰지 않는 이유: 수천~수만 에피소드가 필요하고 보상이 늦게 나오는데, DEM 한 번이 30분~20시간이다. 지도학습은 퍼내기 1회가 곧 정답 달린 샘플 1개라 데이터 효율이 높고, 두 선행(CoDeGa·Aoshima)도 이 구조다.

## 4. 데이터 라벨링 — 사람이 붙이지 않는다

| 정답 | 출처 | 미리 고정할 규칙 |
|---|---|---|
| 잡힌 질량 | 저울(실물) / 툴 내 입자 수(시뮬) | 정착 후 읽는 시점 |
| 퍼낸 뒤 높이지도 | 카메라 / 시뮬 입자 위치 | 집계 방식(max·median, D497) |
| 실제 퍼낸 위치 | 구덩이 중심 관측 | 중심 추출 식 |
| 실패 | 규칙 | 헛퍼내기 문턱·충돌·도달 불가 |

사람이 하는 일은 라벨 계산 규칙을 **실험 전에 동결**하는 것과 불량 샘플(가림·정합 실패) 걸러내기다.

## 5. 데이터 한 행(퍼내기 1회)에 들어갈 것

| 묶음 | 필드 |
|---|---|
| 상태(전) | 높이지도 h_t(max·median), 남은 더미 질량, 상자 자세·카메라 정합 id |
| 행동 | 명령 위치 + 관측 구덩이 중심, 고정 파라미터(깊이·방향·문 각) |
| 결과 | 잡힌 질량, 높이지도 h_{t+1}, 실패 플래그, 사이클 시간 |
| 맥락 | 에피소드 id·단계 t·초기 더미 종류·정책 이름·시드·물성 해시 |
| 시뮬 전용 | 참 높이지도 + 실물 카메라 자세 렌더 높이지도, 툴 내 입자 수 |

에피소드 조건: **같은 더미에서 연속 퍼내기**(선택이 다음을 바꾸는 효과가 데이터에 들어가야 함) · **초기 더미 다양화**(평평한 층만이면 초반 위치 효과가 작을 가능성) · 수집은 무작위 + 규칙 위치, 평가는 같은 초기 더미·시드에서 정책만 바꿔 반복 · 바닥이 드러나는 고갈 구간 포함.

## 6. 학습 순서

| 단계 | 내용 | 판정 |
|---|---|---|
| 0 | 목표(M\*)·지표·기준선 사전등록 | 문서 동결 |
| 1 | 수집 정책·로그 스키마 고정 | 5절 표 |
| 2 | 데이터 수집: 시뮬 퍼내기 셀 pod 병렬(주) + 실물 소량 | 원자료·영수증 |
| 3 | 전처리·자동 라벨·품질 검사·**에피소드/초기 더미 단위 분할** | 데이터셋 버전 |
| 4 | 기준선 평가(학습 없음) — "정책 3개 × 연속 퍼내기 + 위치 민감도" 실험 | 넘어야 할 선 |
| 5 | 예측기 학습(질량 → 형상), 시험 더미에서 오차·불확실성 확인 | RMSE·보정 곡선 |
| 6 | 시뮬 폐루프 계획 평가: 방법① vs ② vs 기준선 | 횟수·시간·실패율 |
| 7 | 실물 이식: 실물 수백 쌍 잔차 GP → 실물 폐루프(최소 8쌍, D497) | 최종 결과 |
| 8 | 능동 수집 → 재학습 | 데이터 추가 |
| 9 | (선택) 예측기 안에서 RL | 계획 속도가 병목일 때만 |

데이터 양 기준점(선행 보고): CoDeGa 실물 5,100회 · Aoshima 시뮬 10,718회, 저차원 출력 약 3,000개에서 포화. 첫 목표 = 시뮬 3,000~10,000쌍 + 실물 수백 쌍.

## 7. "매번 가장 높은 곳만 퍼면 되지 않나"에 대한 입장

좋은 첫 기준선이고 어떤 구간에서는 거의 최적일 수 있다. 우리 숫자로 한 번 ≈12 g, 더미 ≈1,372 g(≈115번), 층 40 mm > 플런지 25 mm 라 **초반엔 어디를 퍼도 툴이 찰 가능성**이 있다(추정, 검증 필요). 최고점 규칙이 질 수 있는 곳은 좁은 봉우리 vs 넓은 평탄부, 벽 근처(도달·충돌 여유), 경사 붕괴, 고갈 구간·카메라 잡음이다. 선행 수치: Aoshima greedy 대비 앞보기 개선 5.6 %(작을 수 있음), CoDeGa 실물 Vol-Max 7.3회 vs 3.1회(목적이 달라 직접 비교 불가), OWLAT 에서 Vol-Max 가 가파른 곳만 골라 실패(재료 1종 보고). 그래서 학습 전에 4단계 기준선 실험으로 **격차가 어디서 나는지부터** 잰다.
