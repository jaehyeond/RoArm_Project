# 퍼내기 위치 학습 — 세부 진행 계획 (2026-09-29)

> 함께 볼 문서: `RoArm_학습방향_정리_20260929.md`(용어·목표/상태/지표 정의·방식 분류), `proposal_priors_package_20260929/`(선행 논문). 수치는 2026-09-29 RunPod 두 run(같은 입력·다른 장비)의 원시 기록 기준이며, 회계·감사 전 값은 그렇게 표시했다.

## 1. 계획을 바꾸는 근거 두 가지

> **정정(2026-09-29 저녁, 메인 원자료 검산)**: 아래 1-1 의 "라벨 = lift_end 툴 안(tool_residual) 개수"는 들린 양을 절반 이하로 센다. podB 들어올린 순간 물리적으로 들린 알 = 832(툴 안 397 + 경계 여유 때문에 '모호'로 분류된 430 + 비행 5). 시뮬 라벨은 분류 코드가 아니라 **기하 기준(더미 위로 들린 알, 되떨어짐 구간 뒤)** 으로 정의하고, 장비 간 일관성(397 vs 388 은 tool_residual 분류만)은 podA 원자료로 재확인한다. 상세 `FULLCYCLE_VS_LEARNING_DATA.md` §3-2.

### 1-1. 라벨은 "용기 배출량"이 아니라 "들어올린 순간 툴 안 개수"
같은 입력으로 돌린 두 run 에서 앞 단계는 거의 같고 뒤 단계에서 크게 갈렸다.

| 시점 | podB (PRO 6000×2) | podA (4090) | 차이 |
|---|---|---|---|
| 첫 닫기 정지 때 툴 안 | 428 | 441 | 3 % |
| **들어올림 끝(lift_end) 툴 안** | **397** | **388** | **2 %** |
| 운반 전 재닫기 문 관절각 | 2.39° | 3.04° | — |
| 운반 중 흘림 | 25 | 123 | 5배 |
| 용기 배출(원시) | 585 | 251 | 2.3배 |

- 배출량 차이는 재닫기 각도와 운반 중 흘림에서 생겼고, 흘림은 시뮬 문 이음새 문제다(실물 운반 유출 ≈0~1알, 2026-09-18 사용자 관찰).
- 따라서 **시뮬 라벨 = lift_end 툴 안 개수(→ g)**, **실물 라벨 = 컵 배출량**(실물은 흘림이 거의 없어 둘이 같다).
- 효과: 데이터 셀에서 운반·배출을 통째로 뺄 수 있다.

### 1-2. 전체 사이클로는 데이터를 못 만든다
- podB 에서 접근 끝 → lift_end (물리 3.5 s) 구간만 ≈4,000 s.
- 퍼내기 구간만 떼어도 67.7k 알 더미에서 1쌍 ≈ PRO 6000×2 1시간·4.7 $ / 4090 2.8시간·2 $ (외삽).
- 1,000쌍이면 2,000~4,700 $ → **데이터 셀 단가를 먼저 실측하고 줄이는 단계가 학습보다 앞에 와야 한다.**

## 2. 단계별 진행 계획

### 0단계 — 정리·사전등록 (podA 완료 후 1일)
1. podA 회수·terminate·R_full 확정, podA 회계(podB 와 같은 절차).
2. 두 run 짝 비교로 **라벨 잡음 폭** 확정(lift_end 397 vs 388 등). "위치에 따른 차이가 잡음보다 큰가"를 판정하는 기준선이 된다.
3. 학습 case 새 폴더·사전등록: 목표(M\*), 라벨 정의(lift_end 툴 안), 지표(횟수·시간·실패율), 기준선 3개, 분할 규칙(에피소드·초기 더미 단위). D500 후보.

### 1단계 — 데이터 셀 제작과 단가 실측 (3~5일, GPU 소량)
1. **연쇄 퍼내기 셀**(rev34 사본 기반): 표면 50 mm 위에서 문 연 채 시작 → 플런지 → 닫기(채터링) → 80 mm 들어올림 → 툴 안 개수 기록(라벨) → 툴 속 알 삭제 → 0.05~0.1 s 정착 → 더미 NPZ 저장 → 다음 위치. 높이지도는 참값 + 실물 카메라 자세 렌더(D469 D-b) 둘 다 저장.
2. 검증 관문(사전등록):
   - 같은 더미·같은 위치(0,0)에서 셀의 lift_end 개수가 전체 사이클 값(388~397)의 변동 폭 안인가
   - 연쇄 질량 보존(삭제 수 = 라벨)
   - 셀당 실제 경과 시간 실측(4090·PRO 6000×2)
3. 단가 줄이기 후보를 **하나씩** 실측(변수 사다리): 관심 반경 밖 알 제거/고정(ROI) · dt 2 µs(사전등록된 사다리) · 필요하면 채터링 OFF. 각 후보는 2번 관문 값과 같아야 채택. D493 경고(알을 줄이면 문 토크 → 포획 변화)를 여기서 직접 확인한다.
4. 관문: 셀 단가 ≤ 약 0.2 $(4090 15분 내외)면 대량 생성으로, 못 미치면 규모를 줄여 2단계만 진행.
5. 병행(로봇 구동 없음): 실물 안식각·부피밀도 측정 → 시뮬 μ·Crr 정합 여부 판단. **대량 생성 전에** 끝내야 잘못된 물성으로 수천 쌍을 만들지 않는다.

### 2단계 — 결정 실험 (학습 없음, 2~3일)
1. 초기 더미 3종: 평평 40 mm(보유) · 원뿔 · 벽 쏠림 경사(로컬 생성 ≈1 h/개).
2. 정책 3개(무작위 · 최고점 · 발자국 부피 최대) × 연속 8회 × 시드 3 = 216 셀 + 위치 민감도(한 상태에서 후보 여러 개) ≈50 셀.
3. 판정:
   - 정책 차이·민감도가 0단계 잡음 폭보다 작다 → "위치가 중요하다" 전제가 약함 → 교수님께 보고하고 방향 조정.
   - 크다 → **어느 구간(고갈·벽·불규칙)에서** 나는지가 3단계 수집 초점.

### 3단계 — 데이터셋 생성 (1~2주, pod 병렬)
1. 수집 정책: 도달 가능 격자 위 무작위 50 % + 최고점 25 % + 부피 최대 25 %, 2단계에서 격차가 난 구간 비중 확대.
2. 목표 3,000쌍(최대 10,000), pod 5~10대 병렬, 셀마다 영수증·sha.
3. 저장: 행마다 높이지도·라벨·맥락 필드(아래 표), 더미 NPZ 는 연쇄에 필요한 것만 유지.
4. 품질 검사·분할(에피소드·초기 더미 단위, 시험용 더미는 학습에 절대 미사용).

| 묶음 | 필드 |
|---|---|
| 상태(전) | 높이지도 h_t(max·median), 남은 더미 질량, 상자 자세·카메라 정합 id |
| 행동 | 명령 위치 + 관측 구덩이 중심, 고정 파라미터(깊이·방향·문 각) |
| 결과 | 라벨(시뮬 lift_end 툴 안 / 실물 컵 배출), 높이지도 h_{t+1}, 실패 플래그, 사이클 시간 |
| 맥락 | 에피소드 id·단계 t·초기 더미 종류·정책 이름·시드·물성 해시 |
| 시뮬 전용 | 참 높이지도 + 실물 카메라 자세 렌더 높이지도 |

### 4단계 — 예측기 학습 (3~5일, 로컬 GPU — "학습"은 사용자 승인 항목, 그때 승인 요청)
1. 넘어야 할 비학습 기준: 발자국 부피 → 개수 선형회귀.
2. 질량 예측기: 위치 중심 32×32 칸(16 cm) 패치 + 벽까지 거리·남은 질량 → 개수 + 불확실성(CNN 5개 앙상블 또는 딥 커널 GP, CoDeGa 식).
3. 형상 예측기: 같은 패치 → 퍼낸 뒤 높이 변화 패치(U-Net). 평가 = 시험 더미 RMSE(mm)·구덩이 깊이·부피 오차.
4. 불확실성 보정 곡선 확인(예측 σ 가 실제 오차와 맞는지).

### 5단계 — 시뮬 폐루프 평가 (1주)
1. 방법①: 질량 예측 최대 위치(탐욕). 방법②: 형상 예측으로 2~4수 앞보기(Aoshima Alg.1 식, 최상위 전수 + 아래 탐욕).
2. 같은 초기 더미·시드에서 방법①·②·기준선 3개를 **실제 DEM 셀로 실행**해 M\* 까지 횟수·실패율 비교.
3. 성공 기준(① > 최선 기준선, ② > ①, 둘 다 잡음 폭 이상)은 실행 전에 동결.

### 6단계 — 실물 트랙 (지금부터 병행, 2~3주)
1. 카메라 연결·손-눈 정합(RMSE ≤5 mm · 조건수 ≤70 · 기울임 자세 ≥12)·반복성 검사(D494~D497). 로봇 구동은 사용자 승인 필요.
2. 실물 100~300쌍: 같은 스키마, 연속 퍼내기, 무작위 + 규칙 위치, 컵 + 0.01 g 저울.
3. 시뮬 예측기의 실물 잔차를 GP 로 보정 → 실물 폐루프 평가(최소 8쌍, D497).
