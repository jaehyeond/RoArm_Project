# 실물 측정과 학습 데이터 만드는 방식 — 정리 (2026-09-30)

> 짝 문서: `LEARNING_PLAN_BRIEF.md` · `LEARNING_PLAN_DETAILED.md` · `FULLCYCLE_VS_LEARNING_DATA.md`. 검토 대상 외부 문서: `~/Downloads/CALIBRATION_AOR_BULK_20260930.md`(다른 저장소 세션 작성, 문헌 수치는 원문 미확인분 포함).

## 0. 요약

- 실물 측정 네 가지는 **데이터 파이프라인을 만드는 데는 필요 없다.** 그러나 **알 질량·치수·모양(1번)은 시뮬 데이터를 대량 생성하기 전에 반드시** 재야 한다. 나머지(마찰·반발·부피밀도·안식각)는 물성 범위를 좁히는 용도라 병행하면 된다.
- 데이터 방식 = **사실 값은 재서 고정 + 모르는 물성은 좁은 범위에서 무작위화 + 실물 소량으로 잔차 보정.**
- 교수님 방향(흘림 배제, 데이터 먼저 → 딥러닝, 높이지도 먼저)은 그대로 유지하고, 보정은 학습을 막지 않는 선에서 병행한다.

## 1. 측정 네 가지는 학습 데이터에 필수인가

| 측정 | 없으면 생기는 문제 | 언제까지 |
|---|---|---|
| 1. 알 질량(100알 × 2번 세기 × 3회)·치수(캘리퍼 30~50알)·모양 비율·고체 밀도(물 치환) | 알 크기 자체가 틀리면(시뮬 20.26 mg vs 9/09 미확정 읽음 0.06 g) 툴에 드는 알 수·구덩이 모양·질량 라벨이 전부 어긋난다. 조정 파라미터가 아니라 **사실 값**이라 보정으로 못 메운다 | **대량 생성 전 필수** |
| 2. 판 미끄럼각 10회·반발 낙하 | 바닥·벽 미끄럼, 튐(흘림·되떨어짐과 연결) | 범위만 |
| 3. 부피밀도(물로 부피 보정한 Ø80~90 mm 원통 + 국자 붓기 5회) | 같은 질량이 몇 mm 층이 되는지(9/29 가정 0.456 → 층 10 % 얇았던 사례) | 범위만 |
| 4. 안식각(고정 관 한 높이 5회) | 퍼낸 뒤 구덩이 벽 무너짐(형상 라벨) | 범위만 |

## 2. 실물·시뮬을 같이 쓸 때 데이터를 만드는 방식

| 방식 | 내용 | 장점 | 단점 | 예 |
|---|---|---|---|---|
| 보정 후 생성 | 물성을 재서 시뮬을 실물에 맞춘 뒤 데이터 생성 | 정확 | 보정 끝날 때까지 생성 지연 | Aoshima(재료 물성 고정 시뮬로 1만 회) |
| 도메인 무작위화 | 모르는 물성을 그럴듯한 범위에서 샘플마다 무작위로 바꿔 생성, 모델이 변화에 강해짐 | 보정 불필요 | 같은 정확도에 데이터 더 필요 | 로봇 sim→real 에서 가장 흔함 |
| 잔차 보정 | 시뮬로 학습 → 실물 소량으로 틀린 만큼 따로 학습해 더함 | 실물 적게 | 시뮬-실물 차가 크면 못 메움 | CoDeGa(평균 모델 + GP) |

**우리 조합**
1. **알 크기·질량·밀도는 재서 고정**(흔들 대상이 아님).
2. **마찰·구름저항·반발은 좁은 범위에서 무작위화**. 범위는 측정 2~4번으로 좁힌다. 샘플마다 쓴 물성 값을 저장해 나중에 실물에 맞는 구간만 고르거나 입력으로 쓴다.
3. **실물 수백 쌍으로 잔차 보정**.
우리 시뮬은 한 쌍이 비싸서(퍼내기 셀 추정 수십 분) 범위를 넓게 잡으면 데이터가 모자란다 → "반쯤 보정 + 좁은 무작위화".

## 3. CALIBRATION_AOR_BULK 문서 검토 요지

**좋은 점**: 시뮬과 같은 조건으로 재는 원칙(고정 노즐·같은 관·붓는 속도·20~80 % 최소제곱·더미 하나 = 표본 1개) · 안식각 하나로는 (μ, Crr) 이 하나로 안 정해진다는 지적 · 알 1개 질량 논리(0.01 g 저울로 한 알씩 달면 ±25 %, 20.26 mg 은 계산값) · 250 mL 실린더 폐기 이유와 물 무게 부피 보정 · 영률 판단의 정직성(겹침 쌓인 더미 p99 ≈0.6 %·문 ≈10 % vs 문헌 0.3 %, "틀림의 증거 아님, 미확인 범위") · 판매 페이지 사실(재료 A 모양 랜덤)과 "못 찾은 것" 분리.

**걸리는 점**
1. 범위가 지금 우선순위(학습·데이터 수집) 대비 크다. 시뮬 격자(클럼프 2~3 × μ × Crr × 시드 3 × 시험 6종)는 DEM 수백 회.
2. **드로다운은 결정을 바꿀 때만.** 목적은 흐름이 아니라 퍼내기 한 번의 들린 양·구덩이 모양이다. 안식각을 맞추는 (μ, Crr) 조합들 사이에서 퍼내기 결과가 거의 안 바뀌면 드로다운은 불필요(AGENTS "결정을 못 바꾸는 검증은 돌리지 않는다").
3. **과업 자체를 보정 시험으로 추가**: 카메라 연결 후 실물 퍼내기 몇 번(알려진 위치·컵 무게·전후 높이지도)이 가장 직접적인 보정 데이터.
4. 저울 용량은 이미 500 g 으로 알려짐. 드로다운 흐름 측정은 1 g 단위 주방 저울(3~5 kg)이 현실적.
5. 반발계수(시뮬 0.30 vs 문헌 0.55~0.65)는 튐·흘림·되떨어짐과 직결 → "(선택)"이 아니라 필수 측정.
6. 3D 출력(깔때기·드로다운 상자)은 `docs/reference/printing.md` 선독 필수(AGENTS).
7. 문헌 수치는 다른 세션 조사 → 우리 문서 인용 전 원문 확인(HARD RULE #4).

**권고 순서**: ① 싼 기초 측정(1~4번, 출력 없이 반나절) → ② 시뮬 알 질량·부피·밀도 수정, 현재 μ 0.45·Crr 0.06 이 안식각 범위 안인지 확인 → ③ 안식각을 맞추는 조합 몇 개로 **시뮬 퍼내기 민감도** 확인 → ④ 민감할 때만 드로다운.

## 4. 교수님 방향에 맞춘 진행(학습·데이터 수집)

1. **흘림은 지금 다루지 않는다**(시뮬 문 이음새 문제로 기록만).
2. **데이터 먼저**: 수집 정책은 스크립트(무작위 + 규칙 위치), 같은 더미에서 연속 퍼내기. 라벨 = 기하 기준 lift_end 들린 알(podA 836 / podB 832, 0.5 % 일치) + 퍼낸 뒤 높이지도.
3. **높이지도 먼저**: 1차 산출물 = 형상 예측기(퍼낸 뒤 높이지도), 평가 = 예측 오차(mm). 질량은 기록만.
4. **그 다음 딥러닝**: 지도학습 예측기 → 탐색 기반 위치 선택(탐욕 vs 앞보기) → 실물 잔차 GP.
5. **보정은 병행**: 측정 1번은 대량 생성 전 필수, 2~4번은 무작위화 범위용.
