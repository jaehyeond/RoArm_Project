## 1. 독립 확인한 절차

1. PPT ZIP의 6개 slide XML과 관계를 읽고 표지 날짜, PBD 8,000개 구형 입자, 내장 슬라이드쇼가 현재 DEME 결과와 다른 자료임을 확인했다. 입력 SHA는 CONTRACT.md와 일치한다. 발표 워커는 notes XML과 내장 PNG도 읽었다.
2. D467/D469 원문과 960 Hz 두 JSON을 내려 읽었다. 관측창 20/10 s와 40/20 s의 형상 경사 20.759768°/16.655137°, 둘 다 미정착. 이는 안정된 재료 안식각도, 관측시간을 통제한 dt-only 곡선도 아니다.
3. 실제 canonical NPZ와 W10/W11 결과 JSON/포획 mask를 직접 읽어 template 동일성, 20,000 clump, 7 sphere/clump, mass·MOI, 541/517개와 환산 질량을 재계산했다. `ROOT_NUMERIC_CROSSCHECK_01.json`에 원본 SHA와 값을 보존했다.
4. `sim_isaac_replay_w12.py:320/338/350/368/404`를 읽었다. 같은 7구 반경·중심으로 만든 mesh, 저장 위치/quaternion 입력, 로봇 관절 상태 쓰기, 매 프레임 Isaac scene step이 존재한다. 입자 PhysX 재계산·DEME로의 피드백은 없다.
5. 기존 lift, first_close, reclose annotated PNG를 직접 열었다. 도구·더미·source/rendered 좌표 표식 및 주석이 보인다. first_close W10은 정지 뒤/lift, W11은 정지 전/close이므로 정확히 같은 이벤트 상태 그림이 아니다. reclose는 둘 다 PF63/phase lift로 정지 약12ms 뒤의 최종 프레임이며 중간 문닫힘을 보여 주지 않는다. 작은 영문 주석이 많아 발표 때 한국어 핵심 캡션이 필요하다. 이 정지이미지로 접촉력·관성값을 계측했다고 주장하지 않는다.
6. W12 paired MP4를 SHA/ffprobe로 확인했다(64 frames, 10 fps, 6.4 s). 전체 연속 영상을 시청하지 않았다. 워커도 PNG 7장 관찰과 MP4 metadata 검토를 분리했다.
7. 설치 DEME의 `FullHertzianForceModel.cu:20/40/69/101`, `DEMCollectForceKernels_Compact.cu:13/35/48`, `DEMIntegrationKernels.cu:155/173/217`를 직접 읽었다. 접촉 상대속도에 회전 성분을 더하고 법선/접선 분해; 질량으로 선가속도, MOI로 각가속도, 각속도로 quaternion 갱신하는 경로를 확인했다. 따라서 입사각 숫자 필드 없음은 방향 효과 없음과 다르다.

## 3. 초기 더미 속도 기록의 구분

canonical NPZ의 metadata `settling_gate.final_m_s`는 max/p99/RMS = 0.024693133/0.000895971/0.000431378 m/s이고, `settle_history[-1]`의 같은 세 속도 칸은 0.021809107/0.000197042/0.000289400 m/s다. 둘 다 저장 시각 표기는 0.750299981 s이다. 메인에서 두 필드를 직접 읽어 차이를 확인했고 물리 워커에 의미 구분을 요청했다. 발표에서는 이를 섞어 하나의 정확한 최종속도로 인용하지 않는다. `settled=true`는 max0.1/p990.002/RMS0.001 m/s의 연속5회 조건 충족을 뜻하며 모든 입자 속도0의 증명이 아니다.
