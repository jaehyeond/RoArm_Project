### 프로포절 구조 (사용자 제공 원안 — 영속화)

  결론부 "RL 계획이 future work") ② Baidu Lu/Zhu/Zhang (RA-L 2022, 2201.11292 —

  못 이김·완주 없음·놓기 스크립트·물체 선택 없음) ③ CMU CraterGrader

  rock picking 이산 모달리티).
- 만들 것: Isaac Sim 테스트베드(기존 자산 재사용), 비정형 물체(22~35mm, 그리퍼
  개구 40~45mm 기준) 더미 + 지정 존, 판단 정책 4개 비교(greedy/최적수송/RL/

## 3. Agent 조사 B — 갭 주장 반증 우선 재검증 (28 질의 × 4소스)

- **⚠️ 최중요 발견 — 프로포절 문장 수정 필수**: **Spinelli et al. 2025 (arXiv
  2508.09003, ETH Hutter 그룹, IEEE T-FR)** — 40t 머티리얼 핸들러 실기에서
  **PPO로 heightmap→파지점(attack point)을 순차 선택, 보상 = 버킷 충전 최대화
  (= 총 사이클 수 최소화)**. ETH 2308.11478의 future work "RL 계획층"을 같은
  그룹이 **pick측은 이미 채움**. 프로포절의 "2025년 후속(ExT)까지 나왔는데도 이
  계획 층은 그대로 비어 있다" 문장은 **그대로 쓰면 반격당함**. 단 Spinelli도
  **place는 학습 안 함**(고정 좌표)·버킷 스쿱(이산 물체 집기 아님).
- 추가 필수 인용: **Lu & Myo (2010-2018, Adelaide)** — 실제 원료야드 도메인에서
  "어느 voxel을 퍼낼지+이동 최소화"라는 동일 결정 문제를 **정수계획법(비학습)**
  으로 푼 최근접 선행. **Schenck 2017 재평가** — scoop 위치+dump 위치를 **둘 다**
  선택했음(단 RL 아니고 목적이 형상) ⇒ "놓기 선택 학습 최초" 단독 주장 금지.
  **Three Springs 2019** — 야드 리클레이머 제어층 RL 상용 실증 ⇒ "야드에 학습
  적용 없음"식 문장 즉시 거짓.
- **판정**: 원료야드 도메인에서 결정층(어디서 집고 어디에 놓을지) 학습 사례
  미발견 — 갭 유지 가능, 확신도 **MEDIUM-HIGH** (HIGH 아님 사유: 포스코DX 세부
  비공개 / Three Springs 제어층 RL 존재 / Semantic Scholar 429 미조회). novelty
  는 **3-결합(재형성 더미 × 완주 총 동작수 × pick+place 양쪽 선택 학습)**으로만
  성립, 어느 단일 축도 "최초" 불가. 안전 문구 초안 + 필수 인용 9편 리스트는
  agent 결과에 확보(본 doc §3이 요지, 상세는 다음 세션에서 프로포절 수정 시 반영).
  **본 절의 금지/한정 규칙은 DECISIONS D450으로 규칙화** — 본 세션 verdict =
  `PIVOT_RECON_COMPLETE__GAP_NARROWED_TO_3_COMBO__GTSU_ANCHOR_CONFIRMED` (D450).

## 5. GTSU 적합성 판정

**GTSU가 앵커 맞음. 단 정확한 프레임 = "pick측 = GTSU(어디서 집나) + place측 =
스태커(어디에 놓나)"의 결합** — GTSU 투하 지점은 고정 호퍼라 놓기 선택이 없고,
놓기 선택이 실재하는 곳은 야드 적치이기 때문. 시나리오 문장은 "원료 체인의 두
결정을 하나의 탁상 사이클로 압축한 축소판"으로. 그랩(감싸 퍼기) ≠ 그리퍼(집기)
차이는 "기여가 결정층 + CMU future work가 이산 집기(rock picking) 지목"으로 방어.

## 6. 그리퍼 커스텀 설계 방향 (착수는 사용자 승인 후)

1. 진단(기존 증거): fg1/D445 — 순정 조 = 수렴 쐐기, 양측 5.5~6.6N 물고도 측방
   배출. 병목은 기하.
2. 역학 논거: 쐐기각 θ > 마찰각이면 (tan θ > μ) 악력 무관 배출 ⇒ **고무링 단독은
   보험일 뿐, 1차 수리는 접촉면 기하**. 고무링 단독안은 대조군으로만.
3. **권장안 = 3D 프린트 조 슬리브(overlay)**: 순정 핑거에 탈착(비가역 개조 0),
   평행 패드+오목 요람(V홈)+TPU/고무 인서트, 질량 5~10g(서보 부담 미미), 접촉
   면적 증가로 필요 악력 감소. **CAD 메쉬 = 실물 프린트 = USD 충돌 기하 동일**
   (D446 교훈: 1-hull 금지, 분해 충돌로 저작).
4. 기구학 함정: RoArm 조 = 단일 회전 ⇒ 평면 패드는 한 개구각에서만 평행. 물체
   창 22~35mm 중점(~28mm)에서 평행하도록 패드각 설계 or 오목/톱니로 둔감화.
   **주 파지 모드 = 근수직 top-down**(t3w/D440: top-down 가능 영역 r∈[0.150,
   0.325m], 완전 수직은 D430 불가·기울임 6~24°) — 설계 목표에 명시.
5. 병행(SW-only): **폭-정지 닫힘 정책** (D445 ②의 미시험 분기) + 토크 캡.
6. 검증 루프: 슬리브 USD → **p17 flying-gripper 13-pose 프로토콜 verbatim 재실행**
   → "순정 0/13 vs 커스텀 X/13" 직접 대조 → 통과 시 프린트 → 실물 개구 재캘리브

   cmd {30,45,60,75,89} 캘리퍼 재실측) → 실물 파지 시험(서보 전류 모니터).
