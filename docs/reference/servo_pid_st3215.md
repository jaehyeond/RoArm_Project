# ST3215 / ST3215-HS 서보 PID 와 RoArm-M3-Pro 펌웨어 — 제대로 쓰는 법 (2026-09-09)

조사 = 80th 세션, 에이전트 2개(서보 제품 / 펌웨어) 병렬 → 코디네이터가 펌웨어 원문으로 재확인.
**하드웨어 실행 0.** 아래 "실기 절차" 는 전부 사용자 승인 후 항목이다.

## 0. 한 줄 결론

PID 는 **서보 안에** 있다(레지스터 21 P · 22 D · 23 I). RoArm-M3 펌웨어는 부팅마다 6관절에
**P=16, I=0** 을 쓰고 D 는 안 건드린다(서보 기본 32 유지) → 출하 상태는 **PD 제어, 적분 없음**.
어깨 3° 처짐은 이 구조의 정상 거동이고, 그리퍼는 **I 를 절대 켜지 않는다**.

제어 법칙 수식은 어느 문서에도 없다. Feetech 원문(중문 교습서 §15): P 크게 → 정지 잠금력↑·동작 뻣뻣 /

## 3. RoArm-M3 펌웨어가 PID 를 다루는 방식

서보 ID(`config.h:69-75`): 베이스 11 · 어깨 12(구동)+13(종동) · 팔꿈치 14 · 손목 15 · 롤 16 · 그리퍼 17. 관절 번호 1~6 순서 동일.

| T | 필드 | 하는 일 | EPROM unlock | 영속 |
|---|---|---|---|---|
| **108** | `joint`(1~6), `p`, `i` | `writeByte(id,21,p)`·`writeByte(id,23,i)`; joint 2 는 12·13 둘 다 (`module.h:940-972`) | 없음 | 아래 §3-1 |
| **109** | — | 6관절 전부 P=16·I=0 (`module.h:976-983`) | 없음 | 아래 §3-1 |
| **503** | `id`, `p` | unlock → `writeByte(id,21,p)` → lock (`module.h:185-191`) | 있음 | **EPROM 영속** |
| **107** | `tor` | 그리퍼(17) **48 번 SRAM** 에 50~1000 (`module.h:398-402`) | 있음(무의미) | 휘발 |
| **112** | `mode,b,s,e,t,r,h` | 전 관절 48 번. ⚠️ 버그: 손목·롤에 `e` 값을 씀 (`module.h:426-427`) | 있음(무의미) | 휘발 |

부팅 순서(`roarm-m3.ino`): `:112 resetPID`(P16/I0) → `:113 moveInit` → `:118 dynamicAdaptation(0, 1000×6)` →
**`:146 handTorqueCtrl(300)`** → `:151-152 boot 미션 재생`. D 는 어디서도 안 씀. JSON **읽기 명령은 없다**(T:1051 은 위치·부하만).

### 3-1. 잠긴 EPROM 에 쓰는 부팅 P=16 이 실제로 먹는가 — 확신 75 %

Feetech 문서는 일관되게 Lock 을 "**저장 여부**"로 설명한다("잠금이면 정전 후 저장 안 됨"), "쓰기 거부"라 하지 않는다.
SCServo `Ack()` 는 체크섬만 보고 잠김 오류 비트도 없다. → 잠긴 채 쓴 21/23 은 **런타임에 적용되고 전원 끄면 사라진다**는
해석이 우세하며, 펌웨어가 매 부팅 다시 쓰므로 실효 P=16 이 유지된다. Waveshare 위키의 "p 기본 16" 도 이 전제 위에 있다.
반증 가능성: "즉시 적용"을 명시한 문장은 없다. **실기 확정 = 레지스터 21 읽기 1회 또는 행동 실험(§5-②).**

## 4. 토크 상한과 과부하 보호 — 기존 문서 정정

- `docs/reference/hardware.md` 의 "T:107 이 EPROM 에 쓴다 · 부팅 시 1000" 은 **오기**. 실제는 SRAM 48 번(휘발)이고,
  소스 0.84 기준 부팅 완료 시 그리퍼 상한은 **300**(`ino:146`). 우리 관측 "재부팅 후 1000" 은 실측이 아니라 `ino:117` 만 읽은 추론이었다.
  실기 펌웨어 버전이 0.84 인지는 미확인(§6).
- **과부하 보호**: 출력 듀티가 36 번(80 %)을 35 번(2 s) 넘게 초과하면 34 번(20 %)으로 강제 강하, 반대 방향 위치 명령으로 해제.
  닫힘 상한 900(=90 %)으로 립에 눌린 채 2 s 가 지나면 보호가 걸릴 수 있다 → **리프트 중 되열림 1~1.6°(D481) 의 후보 원인**.
  회피 후보 = 상한 ≤ 790 (임계가 16 번 기준 절대값 800 이라는 추정) 또는 35 번 250(2.5 s 최대). 36 번 상향은 모터 보호 약화라 비권장.
- 보호 전류 3.25 A / 2 s 는 별개 경로. ST3215-HS 스톨 2.4 A 라 듀티 90 % 장시간 유지는 발열(70 °C 한계) 문제.

## 5. 우리 실기 절차 (전부 사용자 승인 후 · 로봇 켜야 함)

① **실기 펌웨어·피드백 확인**: 부팅 시리얼 로그의 version 문자열, 원시 T:1051 JSON 에 `tG` 가 있는지(소스 0.84 는 출력함 `module.h:617`;
   D481 "tG 없음" 은 `hw_s1_manual.loads()` 가 5개 키만 읽은 탓일 수 있음). 부팅 직후 문을 열어 보며 상한이 300 인지(약하게 움직임) 확인.
② **P 적용 여부 행동 실험**(읽기 명령이 없으므로): 어깨 정지 자세에서 `{"T":108,"joint":2,"p":8,"i":0}` ↔ `p:48` 을 번갈아 주고 처짐·강성 변화를 T:1051 `s` 로 비교.
   변화가 있으면 잠긴 쓰기가 유효(§3-1 확정). 끝나면 `{"T":109}` 로 복귀.
③ **어깨·팔꿈치 3° 처짐** 순서: (a) 명령측 보상(측정 오차만큼 목표를 올림, EPROM 0회, 와인드업 0) → (b) P 16→24→32(출하값) 단계 상승, 각 단계 정지 유지·이동 중 떨림 확인 →
   (c) 그래도 남으면 I 를 작은 값부터, 단 어깨는 12·13 이중 서보라 적분기 둘이 싸울 수 있어 마지막 수단. 기어 백래시 몫(~0.9°)은 어떤 값으로도 안 없어진다.
④ **그리퍼(17) 규칙**: `T:108 joint 6` 에 `i≠0` 금지(정지에 눌린 채 적분 포화 → 해제 시 튐). `T:109` 는 6관절 전부 리셋이므로 어깨 튜닝도 날린다.
   닫힘 유지 시간을 제한하고 63(온도)·69(전류) 대신 `tG`·온도가 없으면 시간으로 관리. 되열림 실험 = 상한 900 vs 790 비교(§4).
⑤ **값 고정은 T:503 이 아니라 boot 미션**: `{"T":222,"name":"boot","step":"{\"T\":108,\"joint\":2,\"p\":24,\"i\":0}"}` — boot 미션은 `resetPID` 뒤에 재생되므로 매 부팅 덮어쓴다.
   T:503 은 순정 펌웨어에서 부팅 `resetPID` 가 16 으로 다시 덮으므로 실익이 없고 EPROM 만 소모한다. T:603 은 boot 미션을 지운다.

## 6. 금지·주의

- 레지스터 18(phase) 수정 금지. 36·13(과부하·온도 한계) 상향 금지. EPROM(주소 < 40) 주기적 쓰기 금지(수명 미공개, 1만 회급 추정).
- unlock 없이 쓴 값이 저장됐다고 가정하지 말 것. `T:107` 은 매 세션(또는 boot 미션) 재전송.
- 맨 `{"T":106}` 금지(D479). 손목 ±90 펌웨어 클램프(D481).

## 7. 미확인·추정

- 잠긴 EPROM 쓰기의 즉시 적용(§3-1) · 과부하 임계가 16 번 기준인지 48 번 기준인지 · EPROM 수명 수치 · P/D/I 스케일과 제어 주기.
- 실기 펌웨어 = 0.84 인지(그리퍼 부팅 상한 300 vs 기존 기록 1000 불일치) · 실기 24/26/27 기본값(문서 16/1 vs 덤프 0/0).
- ST3215-HS 기어비 미공개. 46 번 상한 3400 step/s(≈50 rpm)는 HS 106 rpm 과 불일치 — HS 속도 레지스터 실범위 미확인.
- 제품 비교(위키·제품 페이지): ST3215 30 kg·cm@12 V·0.222 s/60°·스톨 2.7 A / **ST3215-HS 20 kg·cm@12 V(=1.96 N·m 확인)**·0.094 s/60°·스톨 2.4 A·68 g. 메모리 표 동일.
  RoArm-M3-Pro 는 손목2·말단만 비금속 하우징 서보(위키 FAQ) = 그리퍼 HS 라벨과 일치.
